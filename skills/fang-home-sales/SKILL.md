# 房天下成交查询与学区房分析

使用中文。网页查询读取[网页查询规则](references/fang-web.md)；用户要求App字段或分页时读取[App接口使用规则](references/app-api.md)。普通价格展示保留页面遮罩原文；API数值与官方核验结果分开。

## 查询范围与频率

只按用户提供的小区名单或从指定文章中明确列出并核对的小区，逐个查询。先形成城市、小区名称、地址/projcode与来源的清单；同名或范围不清的先核对，不把整个区的成交拉下来再筛选，也不自行扩大到全城或其他小区。

业务查询并发固定为1：搜索、单小区列表、翻页和下一小区串行执行，禁止用多进程、多个脚本、后台任务或多个代理并行查询房天下。相邻业务请求至少间隔5秒，每页最多20条；命中所需日期边界或页数上限即停止，不为补齐全区而继续采集。间隔是保守默认值，不是平台公布的限额。

遇到429、403、验证码、反爬提示、认证失败或异常重复页，停止当前批次并保存已完成进度；不自动重试，不切换IP、设备或账号绕过，也不继续请求下一小区。恢复时从未完成的小区继续，避免重复采集。确需扩大用户给定范围，先明确说明新增范围并取得同意；当前工具不提供全区/全城查询模式。

## 查询成交

先确认城市。优先从用户链接识别；只有小区或学校名称且可能重名时，先查可用上下文，仍不能确定再询问。通过站点城市选择或客户端切换确认该城市提供成交查询；不承诺平台覆盖所有城市或全部交易。

1. 有链接就从原链接打开浏览器并捕获网络；只有小区名则在房天下页面搜索，确认城市、区、小区名和 projcode，禁止猜 ID 或把其他城市、小区的参数直接套用。工具不可用时说明限制，使用用户提供的导出文件。
2. 保存主文档响应、页面配置、实际分页请求 URL、响应正文和采集时间。首屏可能是服务端 HTML，不要只找 JSON。不要把广告和统计请求当成交接口。不要保存 Cookie、认证头和跟踪标识。
3. 从当前 DOM 和响应核对字段，再解析。可运行 `python3 scripts/parse_sales.py response.html --source-url '实际请求URL' --captured-at 'ISO时间' > records.json`，仅需 Python 标准库。支持本样本 HTML，不支持任意 JSON；零记录或页面结构变化时停止并检查响应。
4. 通过实际滚动触发下一页，检查新增记录、请求页码和响应类型。沿用当前页面参数，不能套用通用 page=2 起始规则。对每页记录数量和日期范围做记录；空响应、重复页、验证码、错误或用户指定上限即停止，报告截断。页面 total 不是已获取条数，也不是全市场成交量。没有稳定 ID 时按原始字段标记疑似重复，勿武断合并同日同面积交易。
5. 保留价格原文。带星号为 masked，无价格为 missing，完整数字才可为 exact；exact 只表示平台返回完整数字，不等于官方已核验。价格按页面遮罩原文展示（如 `7**万`、`4**万`），不添加首位分类，不转换为金额区间，不补全数字。仅对同币种、明确“万”单位、完整价格和正面积计算元/㎡（万元×10000÷㎡）。报告总记录数、完整价格数、遮罩数、缺失数和时间范围；价格不可用则不计算均价或涨跌。
6. 提供逐条表：小区、签约日期、面积、户型、朝向、楼层原文、价格原文/状态、完整总价、可计算单价、平台来源标签、来源链接和采集时间。保留原始记录，可导出 JSON/CSV。称为“平台标注签约记录”，不可改称官方网签数据。列出覆盖范围与未验证项。

## 学区房分析

询问缺失且影响判断的入学年份、目标小学/初中、具体门牌、预算/面积和家庭入学条件；能独立查的先查。检索目标年份目标城市、对应区县教育局/政府和学校正式招生公告，保留文件链接、发布日期、适用年份与原文依据。核对施教区精确到门牌及例外、房户一致/实际居住、产权与户籍条件、迁入或持有时间、学位占用规则及过渡安排；每项只按找到的文件表述，不套用别区或往年政策。未公布当年政策时标为待公布，往年仅供参考。

将“官方范围已核对”“中介/平台声称”“门牌或家庭资格待核实”分开。不能从小区名直接保证入学资格；无官方依据不宣称某小区对应某校。成交表与招生证据分别引用。比较总预算、面积、楼层、通勤、价格样本完整性与资格不确定性；样本不足时不推导学区溢价或趋势。用户没要求时不联系中介、不提交个人资料。
